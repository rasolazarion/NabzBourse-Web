# بسته اتصال داده زنده نبض بورس

این بسته برای مخزن `rasolazarion/NabzBourse-Web` آماده شده است. ظاهر اصلی صفحه حفظ شده و اتصال API داخل همان اسکریپت صفحه قرار گرفته است.

## فایل‌ها
- `index.html`: صفحه اصلی با اتصال به API (پس از انتشار API باید آدرس جایگزین شود)
- `server.js`: واسط Node.js برای درخواست به APIهای TSETMC
- `package.json`: وابستگی و فرمان اجرا
- `render.yaml`: تعریف سرویس API برای Render

## انتشار
۱) این چهار فایل را در ریشه مخزن GitHub قرار دهید و `index.html` قبلی را با نسخه این بسته جایگزین کنید.
۲) در Render از New + و سپس Blueprint استفاده کنید و همین مخزن را انتخاب کنید تا سرویس `nabz-bourse-api` ساخته شود.
۳) پس از ساخته شدن سرویس، آدرس عمومی آن را کپی کنید.
۴) در `index.html` مقدار `https://YOUR-API-SERVICE.onrender.com` را با آدرس واقعی سرویس جایگزین کنید و فایل را commit کنید.
۵) در Render بخش Environment سرویس API، مقدار `FRONTEND_ORIGIN` باید `https://nabzbourse-web.onrender.com` باشد.

## تست
- `https://آدرس-API/health` باید JSON با `ok: true` بدهد.
- `https://آدرس-API/api/quote/وبملت` باید اطلاعات نماد را برگرداند (در صورت پاسخ‌گویی TSETMC).

## محدودیت‌ها
این واسط به endpointهای عمومی و مستندنشده TSETMC متکی است و ممکن است با تغییر سرویس مبدأ نیاز به اصلاح داشته باشد. بعضی فیلدها در API فعلی در دسترس نیستند و عمداً با خط تیره نشان داده می‌شوند. RSI، MACD، واگرایی‌ها، هشدارهای خودکار و سیگنال خرید/فروش هنوز پیاده‌سازی نشده‌اند. هیچ قیمت ساختگی نمایش داده نمی‌شود.
